# doomgeneric

The real project doomgeneric of the Rust translator's `tests/manual` ([lookibed/c2das](https://github.com/lookibed/c2das)) converted to daslang by [c2das-re](https://github.com/lookibed/c2das-re), as its head-to-head converts our side. Everything in this directory is generated by `scripts/publish_ports.sh --program doomgeneric` in c2das-re; never edit it, a fix belongs in c2das-re.

## Variants

- `readable/` - for reading and changing the code: Boris, and the weak-model add-a-feature check.
- `fast/` - for running.

`fast/` is converted with `checks: off`: no null or bounds checks, so C bugs are not caught (a null access is a SIGSEGV; an out-of-bounds index reads neighbour memory; AOT keeps its range checks); use `readable/` to debug.

Each variant converts the same program under its own knobs (c2das-re's `ports/variants/`, copied as its `variant.json` with the reason and the numbers behind each knob). x native is the das time over the native build's, above 1 when slower; the lines are the published tree's.

## Running

The modules require c2das-re's `crt` and `c_runtime` modules: a c2das-re checkout at the commit above, with the daScript its `VERSIONS.md` pins built and `scripts/build_crt.sh` run. The program reads its fixture `fixtures/doom1.wad` from the Rust repository's project folder; no fixture is copied here (game data and fixtures stay with their own licenses there). With `<c2das-re>` and `<c2das>` the two checkouts:

```
daslang -load_module <c2das-re>/dasCRuntime -load_module <c2das-re>/c_runtime readable/doom_all/doom_all.das -- <c2das>/tests/manual/doomgeneric/fixtures/doom1.wad
daslang -load_module <c2das-re>/dasCRuntime -load_module <c2das-re>/c_runtime -jit fast/doom_all/doom_all.das -- <c2das>/tests/manual/doomgeneric/fixtures/doom1.wad
# the native build the tables compare with, in <c2das>/tests/manual/doomgeneric:
clang -std=c11 -Iinclude -Iupstream/doomgeneric/doomgeneric -Isrc -O2 src/doom_all.c -o doomgeneric
```

Its output must equal `expected.stdout` of the canonical case `doomgeneric-demo1-std` in the Rust repository's `tests/canonical/cases.json`.

#### `doomgeneric`: `R_DrawColumn`

Ours:

```das
[c_function]
def R_DrawColumn {
    var count : int
    var dest : uint8?
    var frac : int
    var fracstep : int
    count = dc_yh - dc_yl
    // Zero length, column does not exceed a pixel.
    if (count < 0) {
        return
    }
    if (uint(dc_x) >= uint(SCREENWIDTH) || dc_yl < 0 || dc_yh >= SCREENHEIGHT) {
        I_Error`va(cstr("R_DrawColumn: %i to %i at %i"), (dc_yl, dc_yh, dc_x))
    }
    // Framebuffer destination address.
    // Use ylookup LUT to avoid multiply with ScreenWidth.
    // Use columnofs LUT for subwindows?
    dest = ylookup[dc_yl] + columnofs[dc_x]
    // Determine scaling,
    // which is the only mapping to be done.
    fracstep = dc_iscale
    frac = dc_texturemid + (dc_yl - centery) * fracstep
    // Inner loop that does the actual texture mapping,
    // e.g. a DDA-lile scaling.
    // This is as fast as it gets.
    for (_t0 in urange64(uint64(uint(count)) + 1ul)) {
        // Re-map color indices from wall texture column
        // using a lighting/special effects LUT.
        *dest = dc_colormap[int(dc_source[(frac >> FRACBITS) & 127])]
        dest += SCREENWIDTH
        frac += fracstep
    }
}
```

#### `doomgeneric`: `R_DrawSpan`

Ours:

```das
[c_function]
def R_DrawSpan {
    var position : uint
    var step : uint
    var dest : uint8?
    var count : int
    var spot : int
    var xtemp : uint
    var ytemp : uint
    if (ds_x2 < ds_x1 || ds_x1 < 0 || ds_x2 >= SCREENWIDTH || uint(ds_y) > uint(SCREENHEIGHT)) {
        I_Error`va(cstr("R_DrawSpan: %i to %i at %i"), (ds_x1, ds_x2, ds_y))
    }
    // dscount++;
    // Pack position and step variables into a single 32-bit integer,
    // with x in the top 16 bits and y in the bottom 16 bits. For
    // each 16-bit part, the top 6 bits are the integer part and the
    // bottom 10 bits are the fractional part of the pixel position.
    position = (uint(ds_xfrac << 10) & 4294901760u) | uint((ds_yfrac >> 6) & 65535)
    step = (uint(ds_xstep << 10) & 4294901760u) | uint((ds_ystep >> 6) & 65535)
    dest = ylookup[ds_y] + columnofs[ds_x1]
    // We do not check for zero spans here?
    count = ds_x2 - ds_x1
    for (_t0 in urange64(uint64(uint(count)) + 1ul)) {
        // Calculate current texture index in u,v.
        ytemp = (position >> 4u) & 4032u
        xtemp = position >> 26u
        spot = int(xtemp | ytemp)
        // Lookup pixel from flat texture tile,
        // re-index using light/colormap.
        var _t1 = dest
        dest++
        *_t1 = ds_colormap[int(ds_source[spot])]
        position += step
    }
}
```
