# puredoom-readable

The same [PureDOOM](https://github.com/Daivuk/PureDOOM) (`355cfbd`, with `patches/`) converted to daslang twice by [c2das-re](https://github.com/lookibed/c2das-re), source layout, sync build (`doom.c2das`), for "add a feature" tests of a model on each:
- `ugly/` - the default output before the readability phase, c2das-re `c25fca7`; `processed/` - all readability forms, `c_switch`/`c_do_while` and folded C macros (`[c_macro]`), c2das-re `deee320` (full shas in each folder's `c2das-re.commit`). Both play demo1-3 in sync under interp and JIT.
- Needs: a built daScript (the ruling one is the commit c2das-re's `VERSIONS.md` pins; demo1-3 also pass on upstream master `6f83af0855`), cmake and a C++17 compiler, and `freedoom2.wad` (`./fetch_wad.sh` downloads the pinned freedoom 0.13.0 and checks its sha256; no game data is in this repo). No c2das-re checkout: `runtime/` holds the runtime the modules require (`c_runtime/`, das modules, and `dasCRuntime/`, the sources of the native `crt` module), copied by c2das-re's `ports/vendor_runtime.das` at the commit in `runtime/c2das-re.commit`; `check.sh` builds `crt` against your daslang on first use.
- Run: build `crt` once with `cmake -S runtime/dasCRuntime -B runtime/dasCRuntime/_build -DDASLANG_ROOT=$DASLANG_ROOT -DCMAKE_BUILD_TYPE=Release && cmake --build runtime/dasCRuntime/_build` (or run `./check.sh` once), `mkdir run && ln -s $PWD/freedoom2.wad run/doom2.wad`, then `DOOMWADDIR=run $DASLANG_ROOT/bin/daslang -load_module runtime/dasCRuntime -load_module runtime/c_runtime [-jit] processed/doom/doom_main.das -- -timedemo demo1` (without `-jit`: interp).
- Check: `DASLANG_ROOT=<daScript> ./check.sh ugly|processed [interp|jit]` plays demo1-3 and holds every tic's game-state and frame hash to `ref/` (native build logs); exit 0 = nothing broke. `./check.sh` with no arguments lists its options; `C2DAS=<checkout>` uses a c2das-re checkout's runtime and wad instead.
- Tasks: `TASKS.md`, three features behind new switches, each with its check and expected output.
- License: PureDOOM and so both conversions are GPL-2 (`LICENSE`, PureDOOM's own); `runtime/` is c2das-re's, MIT (`runtime/LICENSE`); never edit `ugly/` or `processed/` here except as a test, regenerate them in c2das-re.
