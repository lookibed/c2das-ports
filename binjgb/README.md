# binjgb

The real project binjgb of the Rust translator's `tests/manual` ([lookibed/c2das](https://github.com/lookibed/c2das)) converted to daslang by [c2das-re](https://github.com/lookibed/c2das-re), as its head-to-head converts our side. Everything in this directory is generated by `scripts/publish_ports.sh --program binjgb` in c2das-re; never edit it, a fix belongs in c2das-re.

## Variants

- `readable/` - for reading and changing the code: Boris, and the weak-model add-a-feature check.
- `fast/` - for running.

`fast/` is converted with `checks: off`: no null or bounds checks, so C bugs are not caught (a null access is a SIGSEGV; an out-of-bounds index reads neighbour memory; AOT keeps its range checks); use `readable/` to debug.

Each variant converts the same program under its own knobs (c2das-re's `ports/variants/`, copied as its `variant.json` with the reason and the numbers behind each knob). x native is the das time over the native build's, above 1 when slower; the lines are the published tree's.

## Running

The modules require c2das-re's `crt` and `c_runtime` modules: a c2das-re checkout at the commit above, with the daScript its `VERSIONS.md` pins built and `scripts/build_crt.sh` run. The program reads its fixture `fixtures/cgb-acid2.gbc` from the Rust repository's project folder; no fixture is copied here (game data and fixtures stay with their own licenses there). With `<c2das-re>` and `<c2das>` the two checkouts:

```
daslang -load_module <c2das-re>/dasCRuntime -load_module <c2das-re>/c_runtime readable/binjgb_all/binjgb_all.das -- <c2das>/tests/manual/binjgb/fixtures/cgb-acid2.gbc
daslang -load_module <c2das-re>/dasCRuntime -load_module <c2das-re>/c_runtime -jit fast/binjgb_all/binjgb_all.das -- <c2das>/tests/manual/binjgb/fixtures/cgb-acid2.gbc
# the native build the tables compare with, in <c2das>/tests/manual/binjgb:
clang -std=c11 -Iinclude -Iupstream/binjgb/src -Isrc -DNDEBUG -O2 src/binjgb_all.c -o binjgb
```

Its output must equal `expected.stdout` of the canonical case `binjgb-cgb-acid2-std` in the Rust repository's `tests/canonical/cases.json`.
